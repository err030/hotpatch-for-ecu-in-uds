# References

这个目录当前只放“引用清单”和“迁移说明”，不直接拷贝外部 SDK、FreeRTOS 源码或旧项目产物。

## 原因

- 旧项目体积很大，包含整套 `nRF5 SDK`、`FreeRTOS`、build 产物和测量结果
- 当前仓库仍然以 `software-first` 为主，直接 vendoring 会让结构变重
- 现阶段真正需要保留的是：
  - 哪些文件值得复用
  - 哪些行为语义要从当前仓库移植
  - 哪些内容只是实验数据

## 后续使用方式

- 真要起板级工程时，从这里记录的路径手动抽取最小集合
- 抽出来的内容优先放在 `hardware level/` 下按模块整理
- 不要把旧项目整仓复制进来
